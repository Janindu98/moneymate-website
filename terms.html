2. Description of Application & Offline Architecture

MoneyMate Vault is a Windows desktop application for managing personal finances, tracking income and expenses, organizing bank accounts and salary records, generating financial reports, and creating encrypted local and Google Drive backups of your financial data.

The software is engineered with an offline-first, client-side architecture:

  • Local Data Processing: All calculations, ledger updates, salary breakdowns, and reporting occur directly on your Windows PC.
  • No Developer Server: MoneyMate Vault does not operate remote backend database servers or require central user account registration to manage your ledgers.
  • Device Independence: Your application operates continuously without requiring active internet connectivity for core ledger management.

5. Secure Cloud Backup & Google Drive Integration

MoneyMate Vault provides optional cloud backup capabilities designed to safeguard your financial ledger against hardware failure or device loss:

Google Drive Cloud Backup:

MoneyMate Vault can create encrypted backups of your financial data and store those encrypted backup files in the user's Google Drive. Financial data is encrypted locally before it is uploaded.

When utilizing cloud backup functionality, you agree to the following terms:

  1. Client-Side Encryption: All financial entries are converted into an encrypted .enc file using AES cryptography on your local machine before being uploaded. No unencrypted financial data is transmitted.
  2. User-Controlled Account: Cloud backups are stored directly inside your own Google Drive storage account under your account credentials. MoneyMate Vault developers have no access to your Google account, authentication tokens, or stored files.
